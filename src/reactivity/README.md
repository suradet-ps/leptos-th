# ระบบรีแอกทีฟ (Reactivity)

Leptos ถูกสร้างขึ้นบนระบบรีแอกทีฟแบบละเอียด (fine-grained reactive system) ซึ่งได้รับการออกแบบมาเพื่อสั่งรันผลข้างเคียง (side effects) ที่ใช้ทรัพยากรสูง (เช่น การเรนเดอร์เนื้อหาลงบนเบราว์เซอร์ หรือการยิงคำขอผ่านเครือข่าย) ให้น้อยครั้งที่สุดเท่าที่จะเป็นไปได้ โดยจะตอบสนองเฉพาะเมื่อค่ารีแอกทีฟที่เกี่ยวข้องมีการเปลี่ยนแปลงจริง ๆ เท่านั้น

ที่ผ่านมาเราได้เห็นการทำงานของสัญญาณ (signals) กันไปแล้ว ในบทต่าง ๆ ต่อจากนี้เราจะเจาะลึกการทำงานของระบบนี้มากขึ้น และพาไปทำความรู้จักกับเอฟเฟกต์ (effects) ซึ่งเป็นอีกครึ่งหนึ่งของหัวใจสำคัญในระบบนี้
