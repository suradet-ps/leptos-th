# รีแอกทิวิตี

Leptos ถูกสร้างขึ้นบนระบบรีแอกทีฟแบบละเอียด (fine-grained) ซึ่งออกแบบมาเพื่อรันไซด์เอฟเฟกต์ที่มีค่าใช้จ่ายสูง (เช่น การเรนเดอร์บางสิ่งในเบราว์เซอร์ หรือการส่งคำขอเครือข่าย) ให้น้อยครั้งที่สุดเท่าที่จะเป็นไปได้ เพื่อตอบสนองต่อการเปลี่ยนแปลงของค่ารีแอกทีฟ

จนถึงตอนนี้ เราได้เห็นสัญญาณ (signal) ทำงานแล้ว บทเหล่านี้จะลงลึกขึ้นอีกเล็กน้อย และจะพิจารณาเอฟเฟกต์ ซึ่งเป็นอีกครึ่งหนึ่งของเรื่องราว
