# การดีพลอย

วิธีการดีพลอยเว็บแอปพลิเคชันมีมากพอๆ กับจำนวนนักพัฒนา ยิ่งไม่ต้องพูดถึงจำนวนแอปพลิเคชันเลย แต่มีเคล็ดลับที่เป็นประโยชน์สองสามข้อที่ควรจำไว้เมื่อดีพลอยแอป

## คำแนะนำทั่วไป

1. ข้อควรจำ: ดีพลอยแอป Rust ที่บิลด์ในโหมด `--release` เสมอ ไม่ใช่โหมดดีบัก เรื่องนี้ส่งผลอย่างมหาศาลต่อทั้งประสิทธิภาพและขนาดไบนารี
2. ทดสอบในเครื่องด้วยโหมด release เช่นกัน เฟรมเวิร์กจะทำการปรับปรุงประสิทธิภาพบางอย่างในโหมด release ซึ่งไม่ได้ทำในโหมดดีบัก ดังนั้นบั๊กจึงอาจปรากฏขึ้นได้ตรงจุดนี้ (หากแอปของคุณทำงานแตกต่างออกไปหรือคุณเจอบั๊กจริงๆ นั่นน่าจะเป็นบั๊กในระดับเฟรมเวิร์ก และคุณควรเปิด issue บน GitHub พร้อมตัวอย่างที่ทำซ้ำได้)
3. ดูบท “การปรับขนาดไบนารี WASM ให้เหมาะสม” สำหรับเคล็ดลับเพิ่มเติมเพื่อปรับปรุงเมตริกเวลาจนถึงการโต้ตอบ (time-to-interactive) ของแอป WASM ของคุณในการโหลดครั้งแรกให้ดียิ่งขึ้น

> เราได้ขอให้ผู้ใช้ส่งรูปแบบการดีพลอยของพวกเขามาเพื่อช่วยเขียนบทนี้ ผมจะยกคำพูดจากพวกเขามาไว้ด้านล่าง แต่คุณสามารถอ่านกระทู้ฉบับเต็มได้[ที่นี่](https://github.com/leptos-rs/leptos/issues/1152)
