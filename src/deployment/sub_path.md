# การดีพลอยที่พาธที่ไม่ใช่ราก

จนถึงตอนนี้ ขั้นตอนการดีพลอยได้สมมติว่าแอปพลิเคชันของคุณถูกดีพลอยที่พาธรากของโดเมนของคุณ (`/`) อย่างไรก็ตาม คุณยังสามารถดีพลอยแอปพลิเคชันของคุณที่พาธที่ไม่ใช่รากได้ด้วย เช่น `/my-app`

หากคุณดีพลอยที่พาธที่ไม่ใช่ราก คุณจะต้องทำตามขั้นตอนสองสามอย่างเพื่อบอกส่วนต่างๆ ของแอปพลิเคชันว่าพาธฐานใหม่คืออะไร

## อัปเดต `base` ของเราเตอร์

คอมโพเนนต์ [`<Router/>`](https://docs.rs/leptos_router/latest/leptos_router/components/fn.Router.html) มีพร็อพ `base` ที่ระบุพาธฐานสำหรับการจัดเส้นทาง ตัวอย่างเช่น หากคุณกำลังดีพลอยแอปพลิเคชันที่มีสามหน้า `/`, `/about` และ `/contact` และคุณต้องการให้พวกมันถูกดีพลอยที่ `/my-app` เพื่อให้สามเส้นทางเป็น `/my-app`, `/my-app/about` และ `/my-app/contact` คุณก็จะตั้งพร็อพ `base` เป็น `/my-app`:

```rust
<Router base="/my-app">
    <Routes fallback=|| "Not found.">
        <Route path=path!("/") view=Home/>
        <Route path=path!("/about") view=About/>
        <Route path=path!("/contact") view=Contact/>
    </Routes>
</Router>
```

หากคุณใช้รีเวิร์สพร็อกซี มีแนวโน้มว่าเซิร์ฟเวอร์ของคุณจะ*คิดว่า*มันกำลังให้บริการ `/` ในขณะที่จริงๆ แล้วมันให้บริการ `/my-app` แต่ในเบราว์เซอร์ เราเตอร์จะยังเห็น URL เป็น `/my-app` ในสถานการณ์นี้ คุณควรตั้งพร็อพ `base` อย่างมีเงื่อนไขโดยใช้การคอมไพล์แบบมีเงื่อนไข:
```rust
let base = if cfg!(feature = "hydrate") {
    "/my-app"
} else {
    "/"
};
// ...
<Router base> // ...
```

## อัปเดต `<HydrationScripts root/>`

หากคุณใช้การเรนเดอร์ฝั่งเซิร์ฟเวอร์ คอมโพเนนต์ [`<HydrationScripts/>`](https://docs.rs/leptos/latest/leptos/hydration/fn.HydrationScripts.html) มีหน้าที่โหลด JS/WASM เพื่อไฮเดรตแอป มันมีพร็อพ `root` ของตัวเองที่ระบุพาธฐานสำหรับสคริปต์การไฮเดรต หากสคริปต์เหล่านี้ถูกให้บริการจากไดเรกทอรีย่อยด้วย คุณควรใส่พาธฐานนั้นเป็นพร็อพ `root`

## อัปเดต URL ของฟังก์ชันฝั่งเซิร์ฟเวอร์

หากคุณใช้ฟังก์ชันฝั่งเซิร์ฟเวอร์ โดยค่าเริ่มต้นพวกมันจะส่งคำขอไปที่ `/` หากตัวจัดการฟังก์ชันฝั่งเซิร์ฟเวอร์ของคุณถูกเมานต์ไว้ที่พาธอื่น คุณสามารถตั้งค่านั้นได้ด้วย [`set_server_url`](https://docs.rs/leptos/latest/leptos/server_fn/client/fn.set_server_url.html)

## การตั้งค่า Trunk

หากคุณใช้การเรนเดอร์ฝั่งไคลเอนต์กับ Trunk [ดูเอกสารของ Trunk](https://trunk-rs.github.io/trunk/guide/assets/index.html#directives) เกี่ยวกับวิธีตั้งค่า public URL ผ่าน `--public-url`
