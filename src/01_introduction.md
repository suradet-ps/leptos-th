# บทนำ

หนังสือเล่มนี้จัดทำขึ้นเพื่อแนะนำเว็บเฟรมเวิร์ก [Leptos](https://github.com/leptos-rs/leptos)
โดยจะพาคุณไปทำความรู้จักแนวคิดพื้นฐานที่จำเป็นสำหรับการสร้างแอปพลิเคชัน
เริ่มจากแอปพลิเคชันง่ายๆ ที่เรนเดอร์ในเบราว์เซอร์ ไปจนถึง
แอปพลิเคชันแบบฟูลสแตกที่มีการเรนเดอร์ฝั่งเซิร์ฟเวอร์และการไฮเดรต

คู่มือเล่มนี้ไม่ได้สมมติว่าคุณรู้เรื่องรีแอกทิวิตีแบบละเอียดหรือ
รายละเอียดของเว็บเฟรมเวิร์กสมัยใหม่มาก่อน แต่สมมติว่าคุณคุ้นเคยกับภาษา
โปรแกรม Rust, HTML, CSS, DOM และเว็บ API พื้นฐาน

Leptos มีความคล้ายกับเฟรมเวิร์กอย่าง [Solid](https://www.solidjs.com) (JavaScript)
และ [Sycamore](https://sycamore-rs.netlify.app/) (Rust) มากที่สุด และยังมี
ความคล้ายบางส่วนกับเฟรมเวิร์กอื่นๆ เช่น React (JavaScript), Svelte (JavaScript),
Yew (Rust) และ Dioxus (Rust) ดังนั้นความรู้เกี่ยวกับเฟรมเวิร์กใดเฟรมเวิร์กหนึ่ง
ในกลุ่มนี้อาจช่วยให้เข้าใจ Leptos ได้ง่ายขึ้นด้วย

คุณสามารถดูเอกสารประกอบแบบละเอียดของแต่ละส่วนของ API ได้ที่ [Docs.rs](https://docs.rs/leptos/latest/leptos/)

> ซอร์สโค้ดของหนังสือเล่มนี้อยู่[ที่นี่](https://github.com/leptos-rs/book) ยินดีรับ PR สำหรับการแก้คำผิดหรือทำให้เนื้อหากระจ่างขึ้นเสมอ
