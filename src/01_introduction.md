# บทนำ

หนังสือเล่มนี้จัดทำขึ้นเพื่อแนะนำการใช้งานเว็บเฟรมเวิร์ก [Leptos](https://github.com/leptos-rs/leptos) โดยจะพาคุณไปเรียนรู้แนวคิดพื้นฐานสำคัญที่จำเป็นต่อการพัฒนาเว็บแอปพลิเคชัน ตั้งแต่แอปง่ายๆ ที่เรนเดอร์ในเบราว์เซอร์ ไปจนถึงเว็บแอปแบบฟูลสแตก (full-stack) ที่รองรับการเรนเดอร์ฝั่งเซิร์ฟเวอร์ (Server-Side Rendering หรือ SSR) และการไฮเดรต (Hydration)

เนื้อหาในคู่มือเล่มนี้ไม่จำเป็นต้องมีความรู้เรื่องระบบรีแอกทีฟแบบละเอียด (fine-grained reactivity) หรือเบื้องลึกของเว็บเฟรมเวิร์กยุคใหม่มาก่อน แต่คาดหวังว่าคุณจะคุ้นเคยกับภาษา Rust, HTML, CSS, โครงสร้าง DOM และ Web API พื้นฐานมาบ้างแล้ว

สถาปัตยกรรมของ Leptos มีความใกล้เคียงกับเฟรมเวิร์กอย่าง [Solid](https://www.solidjs.com) (ในโลก JavaScript) และ [Sycamore](https://sycamore-rs.netlify.app/) (ในโลก Rust) มากที่สุด นอกจากนี้ยังมีบางส่วนที่คล้ายคลึงกับเฟรมเวิร์กยอดนิยมอื่นๆ เช่น React (JavaScript), Svelte (JavaScript), Yew (Rust) และ Dioxus (Rust) ดังนั้น หากคุณมีพื้นฐานเฟรมเวิร์กตัวใดตัวหนึ่งในกลุ่มนี้ ก็จะช่วยให้คุณทำความเข้าใจ Leptos ได้รวดเร็วและง่ายดายยิ่งขึ้น

คุณสามารถศึกษาเอกสารอ้างอิงของ API แต่ละส่วนอย่างละเอียดเพิ่มเติมได้ที่ [Docs.rs](https://docs.rs/leptos/latest/leptos/)

> ซอร์สโค้ดของหนังสือเล่มนี้เปิดให้อ่านได้[ที่นี่](https://github.com/leptos-rs/book) เรายินดีรับ Pull Request เสมอ ไม่ว่าจะเป็นการแก้ไขคำผิดหรือการปรับปรุงเนื้อหาให้เข้าใจง่ายขึ้น
