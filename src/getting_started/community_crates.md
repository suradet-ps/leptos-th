# ชุมชน Leptos และครีตตระกูล `leptos-*`

## ชุมชนผู้ใช้งาน Leptos

ก่อนที่เราจะลงมือสร้างแอปพลิเคชันจริง มีอีกหนึ่งเรื่องสำคัญที่อยากแนะนำ: หากคุณยังไม่ได้เข้าร่วม ขอเชิญชวนให้เข้ามาร่วมเป็นส่วนหนึ่งของชุมชน Leptos ที่กำลังเติบโตอย่างอบอุ่น ทั้งบน [Discord](https://discord.gg/YdRAhS7eQB) และบน [Github](https://github.com/leptos-rs/leptos) โดยเฉพาะอย่างยิ่งใน Discord มีผู้ใช้งานที่กระตือรือร้น คอยช่วยเหลือ และเป็นมิตรอย่างมาก เรายินดีต้อนรับทุกคนเสมอ!

```admonish note
หากคุณอ่านเนื้อหาในหนังสือเล่มนี้แล้วพบจุดที่ยังอธิบายไม่ชัดเจน หรือมีข้อสงสัยระหว่างทำตาม คุณสามารถแวะมาพูดคุยในช่อง "docs-and-education" หรือสอบถามในห้อง "help" ได้ทันที เพื่อให้ทีมงานช่วยตอบข้อสงสัย และนำข้อเสนอแนะไปปรับปรุงหนังสือให้ดียิ่งขึ้นสำหรับทุกคน
```

เมื่อคุณเริ่มพัฒนาแอปพลิเคชันไปเรื่อยๆ แล้วเกิดคำถามว่า "จะทำสิ่งนี้ด้วย Leptos อย่างไรดี" คุณสามารถลองค้นหาคำตอบในห้อง "help" บน Discord ดูก่อนได้ เพราะมักจะมีคำถามแนวเดียวกันเคยถูกถามไว้แล้ว หรือจะโพสต์ถามใหม่ได้เลย สมาชิกในชุมชนพร้อมให้ความช่วยเหลือและตอบกลับอย่างรวดเร็วมาก

นอกจากนี้ แท็บ "[Discussions](https://github.com/leptos-rs/leptos/discussions)" บน GitHub ก็เป็นอีกหนึ่งช่องทางที่ยอดเยี่ยมสำหรับการสอบถามปัญหาและติดตามข่าวสารประกาศอัปเดตต่างๆ ของ Leptos

และแน่นอนว่า หากคุณพบเจอบั๊กจากการใช้งาน หรือต้องการเสนอไอเดียฟีเจอร์ใหม่ๆ (หรือต้องการส่งโค้ดแก้บั๊ก / พัฒนาฟีเจอร์เข้ามา) คุณสามารถเปิด Issue ได้โดยตรงที่ [Github issue tracker](https://github.com/leptos-rs/leptos/issues)


## ครีตในระบบนิเวศ `leptos-*`

ชุมชนนักพัฒนาได้ร่วมกันสร้างสรรค์ครีตเสริมสำหรับ Leptos ขึ้นมามากมาย ซึ่งจะช่วยให้คุณทำงานได้เร็วขึ้นและสะดวกสบายยิ่งขึ้น สามารถเข้าไปสำรวจรายชื่อไลบรารีและเครื่องมือที่ชุมชนพัฒนาขึ้นได้ที่คลังรวมลิงก์ [Awesome Leptos](https://github.com/leptos-rs/awesome-leptos) บน GitHub

หากคุณสนใจอยากอัปเดตเครื่องมือและไลบรารีใหม่ล่าสุดที่กำลังอยู่ระหว่างการพัฒนา ลองแวะเข้าไปดูในหมวด "Tools and Libraries" บน Discord ของ Leptos ได้ ในหมวดนั้นจะมีทั้งห้องสนทนาเกี่ยวกับตัวจัดรูปแบบโค้ด (ห้อง "leptosfmt"), ห้องของไลบรารีรวมยูทิลิตี "leptos-use", ห้องของชุด UI Component "thaw-ui" รวมถึงห้อง "libraries" ที่นักพัฒนาใช้พูดคุยแลกเปลี่ยนไอเดียครีต `leptos-*` ใหม่ๆ ก่อนที่จะนำไปรวบรวมไว้ใน [Awesome Leptos](https://github.com/leptos-rs/awesome-leptos) ต่อไป
