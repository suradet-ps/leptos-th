# ชุมชน Leptos และครีต `leptos-*`

## ชุมชน

หมายเหตุสุดท้ายก่อนที่เราจะเริ่มสร้างด้วย Leptos: หากคุณยังไม่ได้เข้าร่วม เชิญเข้าร่วมชุมชนที่กำลังเติบโตบน [Discord](https://discord.gg/YdRAhS7eQB) ของ Leptos และบน [Github](https://github.com/leptos-rs/leptos) ได้เลย ช่อง Discord ของเรามีความคึกคักและเป็นมิตรเป็นพิเศษ - เรายินดีมากที่จะมีคุณอยู่ที่นั่น!

```admonish note
หากคุณพบบทหรือคำอธิบายที่ไม่ชัดเจนระหว่างที่คุณอ่านหนังสือ Leptos อยู่ เพียงแจ้งในช่อง "docs-and-education" หรือถามคำถามในช่อง "help" เพื่อให้เราช่วยอธิบายให้กระจ่างและอัปเดตหนังสือให้ผู้อื่นต่อไป
```

เมื่อคุณก้าวหน้าไปไกลขึ้นในการเดินทางกับ Leptos และพบว่าคุณมีคำถามเกี่ยวกับ "จะทำ 'x' ด้วย Leptos ได้อย่างไร" ให้ค้นหาในช่อง "help" ของ Discord ว่ามีคนถามคำถามคล้ายกันมาก่อนหรือไม่ หรือจะโพสต์คำถามของคุณเองก็ได้ - ชุมชนเราช่วยเหลือดีและตอบเร็วมาก

"[Discussions](https://github.com/leptos-rs/leptos/discussions)" บน Github ก็เป็นที่ที่ดีสำหรับการถามคำถามและติดตามประกาศต่างๆ เกี่ยวกับ Leptos เช่นกัน

และแน่นอน หากคุณพบบั๊กขณะพัฒนาด้วย Leptos หรือต้องการขอฟีเจอร์ใหม่ (หรือมีส่วนร่วมแก้บั๊ก / เพิ่มฟีเจอร์ใหม่) ก็สามารถเปิด issue ได้ที่[ระบบติดตาม issue บน Github](https://github.com/leptos-rs/leptos/issues)


## ครีต Leptos-*

ชุมชนได้สร้างครีตที่เกี่ยวข้องกับ Leptos มากขึ้นเรื่อยๆ ซึ่งจะช่วยให้คุณทำงานกับโปรเจกต์ Leptos ได้อย่างมีประสิทธิภาพเร็วขึ้น - ดูรายการครีตที่สร้างบน Leptos และมีส่วนร่วมโดยชุมชนได้ที่รีโพ [Awesome Leptos](https://github.com/leptos-rs/awesome-leptos) บน Github

หากคุณต้องการค้นหาครีตใหม่ๆ ที่เกี่ยวข้องกับ Leptos ที่กำลังมาแรง ลองดูส่วน "Tools and Libraries" ของ Leptos Discord ในส่วนนั้นมีช่องสำหรับฟอร์แมตเตอร์มาโคร `view!` ของ Leptos (ในช่อง "leptosfmt") มีช่องสำหรับไลบรารียูทิลิตี "leptos-use" อีกช่องสำหรับไลบรารีคอมโพเนนต์ UI "thaw-ui" และช่อง "libraries" ที่ครีต `leptos-*` ใหม่ๆ ถูกพูดคุยกันก่อนจะถูกเพิ่มเข้าไปในรายการครีตและแหล่งข้อมูลที่มีอยู่บน [Awesome Leptos](https://github.com/leptos-rs/awesome-leptos) ต่อไป
