# ทำความรู้จักกับ `cargo-leptos`

จนถึงตอนนี้ เราเพียงแค่รันโค้ดในเบราว์เซอร์และใช้ Trunk ในการจัดการกระบวนการบิลด์และรันเซิร์ฟเวอร์สำหรับการพัฒนาบนเครื่องเท่านั้น แต่หากเราต้องการเพิ่มการเรนเดอร์ฝั่งเซิร์ฟเวอร์ (SSR) เราจำเป็นต้องรันโค้ดแอปพลิเคชันของเราบนเซิร์ฟเวอร์ด้วย ซึ่งหมายความว่าเราต้องคอมไพล์ไบนารีออกมา 2 ตัวแยกจากกัน: ตัวแรกคอมไพล์เป็นเนทีฟไบนารีเพื่อรันบนเซิร์ฟเวอร์ ส่วนอีกตัวคอมไพล์เป็น WebAssembly (WASM) เพื่อส่งไปรันในเบราว์เซอร์ของผู้ใช้ นอกจากนี้ เซิร์ฟเวอร์ยังต้องรู้วิธีเสิร์ฟไฟล์ WASM ตัวนี้ (รวมถึง JavaScript ตัวเริ่มต้นที่จำเป็น) ส่งกลับไปยังเบราว์เซอร์ด้วย

แม้ว่าจะไม่ใช่เรื่องที่ยากเกินความสามารถ แต่มันก็เพิ่มความซับซ้อนขึ้นมาพอสมควร เพื่อความสะดวกสบายและประสบการณ์การพัฒนาที่ราบรื่นยิ่งขึ้น เราจึงได้สร้างเครื่องมือบิลด์ชื่อ [`cargo-leptos`](https://github.com/leptos-rs/cargo-leptos) ขึ้นมา โดยหน้าที่หลักของ `cargo-leptos` คือการประสานและควบคุมกระบวนการบิลด์ทั้งหมดสำหรับแอปของคุณ จัดการคอมไพล์โค้ดฝั่งเซิร์ฟเวอร์และฝั่งไคลเอนต์ใหม่โดยอัตโนมัติเมื่อมีการแก้ไขโค้ด รวมถึงมีฟีเจอร์ในตัวสำหรับสนับสนุนสิ่งต่าง ๆ เช่น Tailwind, SASS และการทดสอบ

การเริ่มต้นใช้งานทำได้ง่ายมาก เพียงแค่รันคำสั่ง:

```bash
cargo install --locked cargo-leptos
```

จากนั้นเมื่อต้องการสร้างโปรเจกต์ใหม่ คุณสามารถเลือกใช้เทมเพลตใดเทมเพลตหนึ่งได้ดังนี้:

```bash
# for an Actix template
cargo leptos new --git https://github.com/leptos-rs/start-actix
```

หรือ

```bash
# for an Axum template
cargo leptos new --git https://github.com/leptos-rs/start-axum
```

อย่าลืมตรวจสอบให้แน่ใจว่าคุณได้ติดตั้ง target `wasm32-unknown-unknown` เรียบร้อยแล้ว เพื่อให้คอมไพเลอร์ Rust สามารถคอมไพล์โค้ดของคุณให้เป็น WebAssembly สำหรับรันบนเบราว์เซอร์ได้:
```bash
rustup target add wasm32-unknown-unknown
```

จากนั้นให้ `cd` เข้าไปยังไดเรกทอรีโปรเจกต์ที่คุณเพิ่งสร้างขึ้น แล้วรันคำสั่ง:

```bash
cargo leptos watch
```

เมื่อแอปพลิเคชันของคุณคอมไพล์เสร็จเรียบร้อย คุณสามารถเปิดเบราว์เซอร์ไปที่ [`http://localhost:3000`](http://localhost:3000) เพื่อดูผลลัพธ์ได้ทันที

`cargo-leptos` ยังมีฟีเจอร์เพิ่มเติมและเครื่องมือในตัวอีกมากมาย คุณสามารถศึกษาข้อมูลเพิ่มเติมได้[ใน `README` ของโปรเจกต์](https://github.com/leptos-rs/cargo-leptos/blob/main/README.md)

แต่เกิดอะไรขึ้นเบื้องหลังกันแน่เมื่อคุณเปิดเบราว์เซอร์ไปยัง `localhost:3000`? มาอ่านต่อในบทถัดไปเพื่อหาคำตอบกัน
