# ส่วนที่ 2: การเรนเดอร์ฝั่งเซิร์ฟเวอร์

อย่างที่คุณได้อ่านในบทที่แล้ว การใช้เว็บแอปพลิเคชันที่เรนเดอร์ฝั่งไคลเอนต์นั้นมีข้อจำกัดบางประการ ส่วนที่สองของหนังสือเล่มนี้จะกล่าวถึงวิธีใช้การเรนเดอร์ฝั่งเซิร์ฟเวอร์เพื่อเอาชนะข้อจำกัดเหล่านี้ และเพื่อให้ได้ประสิทธิภาพและ SEO ที่ดีที่สุดจากแอป Leptos ของคุณ


```admonish info

เมื่อทำงานกับ Leptos ฝั่งเซิร์ฟเวอร์ คุณสามารถเลือกได้อย่างอิสระระหว่างการผสานรวม Actix หรือ Axum ที่ได้รับการสนับสนุนอย่างเป็นทางการ หรือตัวเลือกที่ชุมชนสนับสนุน ฟีเจอร์ครบชุดของ Leptos ใช้ได้กับการเลือกแบบทางการ ส่วนแบบที่ชุมชนสนับสนุนอาจรองรับได้น้อยกว่า ตรวจสอบเอกสารของแต่ละตัวสำหรับรายละเอียด

เรามีตัวเลือกที่ชุมชนสนับสนุนหลากหลาย รวมถึงรันไทม์ที่เข้ากันได้กับ WinterCG อย่าง Deno หรือ Cloudflare และรันไทม์ WASM ฝั่งเซิร์ฟเวอร์อย่าง Spin การผสานรวมที่ชุมชนสนับสนุนสำหรับ Viz และ Pavex ก็มีตัวเลือกเซิร์ฟเวอร์แบบดั้งเดิมให้มากกว่า การเขียนการผสานรวมด้วยตัวเองไม่แนะนำสำหรับผู้เริ่มต้น แต่ผู้ใช้ Rust ระดับกลาง/สูงอาจต้องการลองทำ เรายินดีเสมอหากคุณมีคำถามเกี่ยวกับเรื่องนี้บน Discord หรือ Github ของเรา

ผมขอแนะนำ Axum หรือ Actix สำหรับผู้เริ่มต้น ทั้งสองทำงานได้เต็มรูปแบบ และการเลือกระหว่างสองตัวนี้เป็นเรื่องของความชอบส่วนบุคคล ไม่มีตัวเลือกใดผิด แต่ถ้าคุณกำลังมองหาคำแนะนำ ทีม Leptos ปัจจุบันใช้ Axum เป็นค่าเริ่มต้นสำหรับโปรเจกต์ใหม่
```
