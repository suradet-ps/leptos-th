# ส่วนที่ 1: การสร้างส่วนติดต่อผู้ใช้

ในส่วนแรกของหนังสือ เราจะมาดูการสร้างส่วนติดต่อผู้ใช้ฝั่งไคลเอนต์ด้วย Leptos ภายใต้ฮู้ดนั้น Leptos และ Trunk จะรวมโค้ด JavaScript ชิ้นเล็กๆ ที่จะโหลด UI ของ Leptos ซึ่งคอมไพล์เป็น WebAssembly เพื่อขับเคลื่อนการโต้ตอบในเว็บไซต์ CSR (ที่เรนเดอร์ฝั่งไคลเอนต์) ของคุณ

ส่วนที่ 1 จะแนะนำเครื่องมือพื้นฐานที่คุณต้องใช้ในการสร้างส่วนติดต่อผู้ใช้แบบรีแอกทีฟที่ขับเคลื่อนด้วย Leptos และ Rust เมื่อจบส่วนที่ 1 คุณควรจะสามารถ
สร้างเว็บไซต์แบบซิงโครนัสที่ตอบสนองฉับไวซึ่งเรนเดอร์ในเบราว์เซอร์ และที่คุณสามารถดีพลอยบนบริการโฮสติ้งเว็บไซต์แบบสแตติกใดๆ เช่น Github Pages หรือ Vercel ได้

```admonish info
เพื่อให้ได้ประโยชน์สูงสุดจากหนังสือเล่มนี้ เราขอแนะนำให้คุณเขียนโค้ดตามตัวอย่างที่ให้ไว้
ในบท [เริ่มต้นใช้งาน](https://book.leptos.dev/getting_started/) และ [Leptos DX](https://book.leptos.dev/getting_started/leptos_dx.html) เราได้แสดงวิธีตั้งค่าโปรเจกต์พื้นฐานด้วย Leptos และ Trunk รวมถึงการจัดการข้อผิดพลาด WASM ในเบราว์เซอร์
การตั้งค่าพื้นฐานนั้นเพียงพอที่จะเริ่มต้นพัฒนา Leptos ได้แล้ว

หากคุณต้องการเริ่มต้นด้วยเทมเพลตที่ครบครันกว่าซึ่งสาธิตวิธีตั้งค่าพื้นฐานบางอย่างที่คุณจะพบในโปรเจกต์ Leptos จริง เช่น การจัดเส้นทาง (จะกล่าวถึงในบทต่อๆ ไป) การแทรกแท็ก `<Title>` และ `<Meta>` ลงใน head ของหน้าเว็บ และความสะดวกอื่นๆ อีกเล็กน้อย ก็สามารถใช้รีโพเทมเพลต [leptos-rs `start-trunk`](https://github.com/leptos-rs/start-trunk) เพื่อเริ่มต้นได้เลย

เทมเพลต `start-trunk` ต้องมี `Trunk` และ `cargo-generate` ติดตั้งอยู่ ซึ่งคุณได้จากการรัน `cargo install trunk` และ `cargo install cargo-generate`

หากต้องการใช้เทมเพลตเพื่อตั้งค่าโปรเจกต์ของคุณ เพียงรัน

`cargo generate --git https://github.com/leptos-rs/start-trunk`

จากนั้นรัน

`trunk serve --port 3000 --open`

ในไดเรกทอรีของแอปที่สร้างใหม่เพื่อเริ่มพัฒนาแอปของคุณ
เซิร์ฟเวอร์ Trunk จะรีโหลดแอปของคุณเมื่อไฟล์มีการเปลี่ยนแปลง ทำให้การพัฒนาเป็นไปอย่างราบรื่น

```
