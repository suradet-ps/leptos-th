# ส่วนที่ 1: การสร้างส่วนติดต่อผู้ใช้ (UI)

ในส่วนแรกของหนังสือเล่มนี้ เราจะมาเรียนรู้การสร้างส่วนติดต่อผู้ใช้ (User Interface) ฝั่งไคลเอนต์ด้วย Leptos การทำงานเบื้องหลังคือ Leptos และ Trunk จะทำการรวมสคริปต์ JavaScript ตัวเล็กๆ ที่ทำหน้าที่โหลด UI ของ Leptos ซึ่งถูกคอมไพล์เป็น WebAssembly (WASM) เพื่อขับเคลื่อนการโต้ตอบของหน้าเว็บในโหมด Client-Side Rendering (CSR)

เนื้อหาในส่วนที่ 1 จะแนะนำเครื่องมือและแนวคิดพื้นฐานทั้งหมดที่คุณจำเป็นต้องรู้ เพื่อสร้าง UI แบบรีแอกทีฟด้วย Leptos และ Rust เมื่ออ่านจบส่วนนี้ คุณจะสามารถสร้างเว็บไซต์แบบซิงโครนัสที่ตอบสนองรวดเร็ว เรนเดอร์บนเบราว์เซอร์ได้ทันใจ และพร้อมนำไปดีพลอยบนบริการ Static Hosting ชั้นนำ เช่น GitHub Pages หรือ Vercel ได้อย่างมั่นใจ

```admonish info
เพื่อให้ได้ประโยชน์สูงสุดจากหนังสือเล่มนี้ เราขอแนะนำให้คุณเปิดคอมไพเลอร์แล้วลองเขียนโค้ดตามตัวอย่างไปด้วย
ในบท [เริ่มต้นใช้งาน](https://book.leptos.dev/getting_started/) และ [Leptos DX](https://book.leptos.dev/getting_started/leptos_dx.html) เราได้แสดงวิธีตั้งค่าโปรเจกต์พื้นฐานด้วย Leptos และ Trunk รวมถึงการดักจับข้อผิดพลาดของ WASM บนเบราว์เซอร์ไว้แล้ว ซึ่งการตั้งค่าเบื้องต้นนั้นก็เพียงพอให้คุณเริ่มทดลองเขียน Leptos ได้ทันที

แต่หากคุณต้องการเริ่มต้นจากเทมเพลตที่มีฟีเจอร์ครบครันยิ่งขึ้น เพื่อดูตัวอย่างโครงสร้างที่มักใช้จริงในโปรเจกต์ เช่น การจัดเส้นทาง (Routing ซึ่งจะกล่าวถึงในบทต่อๆ ไป), การแทรกแท็ก `<Title>` และ `<Meta>` ลงในส่วน `<head>` ของหน้าเว็บ และลูกเล่นอื่นๆ คุณสามารถนำเทมเพลต [start-trunk ของ leptos-rs](https://github.com/leptos-rs/start-trunk) มาใช้งานได้ทันที

เทมเพลต `start-trunk` กำหนดให้คุณต้องติดตั้ง `Trunk` และ `cargo-generate` ก่อน โดยรันคำสั่ง `cargo install trunk` และ `cargo install cargo-generate`

จากนั้นสร้างโปรเจกต์ใหม่จากเทมเพลตด้วยคำสั่ง:

`cargo generate --git https://github.com/leptos-rs/start-trunk`

แล้วรันคำสั่ง:

`trunk serve --port 3000 --open`

ในไดเรกทอรีโปรเจกต์ที่เพิ่งสร้างขึ้น เพื่อเริ่มพัฒนาเว็บแอปของคุณ
ตัวเซิร์ฟเวอร์ของ Trunk จะคอยตรวจจับการแก้ไขไฟล์และรีโหลดหน้าเว็บให้อัตโนมัติ ทำให้ขั้นตอนการพัฒนาราบรื่นไร้รอยต่อ
```
