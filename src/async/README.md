# การทำงานกับ `async`

จนถึงตอนนี้ เราได้ทำงานกับส่วนติดต่อผู้ใช้แบบซิงโครนัสเท่านั้น คุณป้อนข้อมูลบางอย่าง
แอปก็ประมวลผลทันทีและอัปเดตส่วนติดต่อผู้ใช้ นี่เป็นเรื่องที่ดี แต่มันเป็นเพียงส่วนเสี้ยวเล็กๆ
ของสิ่งที่เว็บแอปพลิเคชันทำ โดยเฉพาะอย่างยิ่ง เว็บแอปส่วนใหญ่ต้องจัดการกับการโหลดข้อมูลแบบ
อะซิงโครนัส ซึ่งมักเป็นการโหลดบางอย่างจาก API

ข้อมูลแบบอะซิงโครนัสขึ้นชื่อว่าผสานเข้ากับส่วนที่เป็นซิงโครนัสของโค้ดคุณได้ยากมาก
เพราะปัญหาเรื่อง “การระบายสีฟังก์ชัน (function coloring)”

ในบทต่อๆ ไป เราจะได้เห็นพริดิมิตีฟรีแอกทีฟสองสามตัวสำหรับทำงานกับข้อมูลแบบอะซิงก์ แต่สิ่งสำคัญ
ที่ต้องย้ำตั้งแต่แรกคือ: ถ้าคุณเพียงแค่ต้องการทำงานอะซิงโครนัสบางอย่าง Leptos มีฟังก์ชัน
[`spawn_local`](https://docs.rs/leptos/latest/leptos/task/fn.spawn_local.html)
ที่ทำงานได้ข้ามแพลตฟอร์ม ซึ่งทำให้การรัน `Future` เป็นเรื่องง่าย หากพริดิมิตีฟตัวใดที่
กล่าวถึงในส่วนที่เหลือของบทนี้ดูไม่ตรงกับสิ่งที่คุณต้องการ ลองพิจารณาผสม `spawn_local`
เข้ากับการตั้งค่าสัญญาณดู

แม้ว่าพริดิมิตีฟที่กำลังจะกล่าวถึงจะมีประโยชน์มาก และบางครั้งถึงขั้นจำเป็น บางครั้งผู้คนก็
เจอสถานการณ์ที่พวกเขาต้องการเพียงสปอว์นงานหนึ่งงานแล้วรอให้มันเสร็จก่อนจะทำอย่างอื่น
ในสถานการณ์แบบนั้นก็ใช้ `spawn_local` เลย!
