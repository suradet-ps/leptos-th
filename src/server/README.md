# การทำงานกับเซิร์ฟเวอร์

ส่วนก่อนหน้าได้อธิบายกระบวนการเรนเดอร์ฝั่งเซิร์ฟเวอร์ โดยใช้เซิร์ฟเวอร์เพื่อสร้างเวอร์ชัน HTML ของหน้าเพจที่จะกลายเป็นอินเทอร์แอกทีฟในเบราว์เซอร์ จนถึงตอนนี้ ทุกอย่างเป็น “ไอโซมอร์ฟิก” กล่าวอีกนัยหนึ่ง แอปของคุณมี “รูปร่าง (_morphe_) ที่เหมือนกัน (_iso_)” ทั้งบนไคลเอนต์และเซิร์ฟเวอร์

แต่เซิร์ฟเวอร์ทำได้มากกว่าการเรนเดอร์ HTML มาก! ที่จริงแล้ว เซิร์ฟเวอร์สามารถทำสิ่งต่างๆ มากมายที่เบราว์เซอร์ของคุณ_ทำไม่ได้_ เช่น การอ่านและเขียนฐานข้อมูล SQL

ถ้าคุณคุ้นเคยกับการสร้างแอปฟรอนต์เอนด์ JavaScript คุณคงคุ้นเคยกับการเรียก REST API บางประเภทเพื่อทำงานฝั่งเซิร์ฟเวอร์แบบนี้ ถ้าคุณคุ้นเคยกับการสร้างเว็บไซต์ด้วย PHP หรือ Python หรือ Ruby (หรือ Java หรือ C# หรือ...) งานฝั่งเซิร์ฟเวอร์นี้ก็เป็นเรื่องปกติสำหรับคุณ และความสามารถในการโต้ตอบฝั่งไคลเอนต์มักเป็นสิ่งที่คิดทีหลัง

ด้วย Leptos คุณทำได้ทั้งสองอย่าง: ไม่ใช่แค่ในภาษาเดียวกัน ไม่ใช่แค่แชร์ชนิดข้อมูลเดียวกัน แต่ยังอยู่ในไฟล์เดียวกันด้วย!

ส่วนนี้จะพูดถึงวิธีสร้างส่วนต่างๆ ของแอปพลิเคชันของคุณที่เป็นเอกลักษณ์เฉพาะฝั่งเซิร์ฟเวอร์
